# Active Workset

This file describes how to interpret the workspace control plane.

## Rules

1. `projects/registry/projects.json` determines which projects are active.
2. `projects/registry/active.md` is the human dashboard for active and paused projects.
3. `projects/registry/now-working.md` records the current session focus.
4. `projects/registry/machine-sync.md` is a generated snapshot, not the source of truth.
