# End Session

## Goal

Leave both the team workspace and active code repos in a recoverable state for the next machine or next session.

## Required steps

1. Update `team/handoffs.md` for the active project if work is incomplete.
2. Update `team/decisions.md` if a material decision was made.
3. Update `ops/risk-log.md` or `reporting/history/` if delivery state changed.
4. Commit and push `opencode_profile` if operational state changed.
5. Commit and push code repos as appropriate.
6. Update `projects/registry/now-working.md` if session focus changed.

## Minimum handoff content

1. Current focus
2. What changed
3. What is incomplete
4. Risks or blockers
5. Recommended next step
