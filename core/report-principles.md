# Report Principles

## Reporting goals

The weekly report must show both engineering progress and delivery or commercial context.

## Required sections

1. Overall status
2. Completed this week
3. In progress
4. Blockers and risks
5. Commercial notes
6. Next week
7. Evidence and mismatches

## Quality bar

1. Anchor project status to the Jira Epic.
2. Cross-check Jira with code or repo activity.
3. Flag mismatches between issue status and technical reality.
4. Keep Jira output short and actionable.
5. Keep Notion output readable over time.

## Publishing mode

Reports are generated as drafts only.
