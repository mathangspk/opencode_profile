# New Project Home Checklist

## Goal

Create the team workspace operating home for a project before real execution begins.

## Steps

1. Create the project home with `install/new-project-home.ps1`.
2. Fill `profile.md` with identity, repo, Jira, and Notion fields.
3. Fill `reporting/config.json` with reporting and publish settings.
4. Review `team/working-agreements.md` and customize project-specific rules.
5. Update `ops/state.json` with the initial lifecycle and focus.
6. Install the code workspace scaffold if needed.
