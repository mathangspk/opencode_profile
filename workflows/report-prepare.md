# Report Prepare Workflow

## Goal

Resolve the effective reporting contract for a project before drafting Jira and Notion updates.

## Inputs

1. `projects/<domain>/<project>/profile.md`
2. `projects/<domain>/<project>/reporting/config.json`
3. `projects/<domain>/<project>/reporting/workflow.md`
4. Latest draft and published snapshots if available
5. Jira and repo state

## Steps

1. Read the project profile and reporting config.
2. Read the project-specific reporting overrides.
3. Read the latest draft and published snapshots.
4. Compare Jira status, repo reality, and local notes.
5. Build a factual summary before drafting outputs.
