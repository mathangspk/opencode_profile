# Handoff Workflow

## Purpose

Use this workflow when pausing work mid-stream or switching context.

## Output sections

1. Current focus
2. What changed
3. What is incomplete
4. Known blockers
5. Recommended next action

## Rules

1. Keep it short.
2. Include references to the Jira Epic and active issue keys.
3. Mention local-only work if it has not yet been reflected in Jira.
