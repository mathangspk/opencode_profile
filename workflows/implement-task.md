# Implement Task Workflow

## Use when

The scope is already clear and ready for implementation.

## Inputs

1. Project profile
2. Scoped task
3. Relevant files
4. Acceptance expectations

## Outputs

1. Files touched
2. Change summary
3. Assumptions
4. Remaining risks
5. Suggested validation

## Rules

1. Keep changes minimal.
2. Escalate if the task requires unapproved architecture work.
