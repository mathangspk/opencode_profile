# Explore Project Workflow

## Use when

1. The project is unfamiliar.
2. The task scope is ambiguous.
3. The primary agent needs relevant file boundaries before implementation.

## Inputs

1. Project profile
2. Task summary
3. Repo structure
4. Key config and entry points

## Outputs

1. Project summary
2. Relevant files and directories
3. Key boundaries and unknowns
4. Recommended next agent

## Rules

1. Keep the scope narrow.
2. Stop before implementation or review.
