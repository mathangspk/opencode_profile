# Test And Validate Workflow

## Use when

1. Implementation is complete enough for validation.
2. Review findings need behavioral confirmation.
3. A release or stakeholder check needs confidence.

## Inputs

1. Project profile
2. Change summary
3. Acceptance checks
4. QA mode from the project profile

## Outputs

1. Scope tested
2. Scenarios checked
3. Findings
4. Coverage gaps
5. Pass/fail recommendation

## Rules

1. Use the project QA mode.
2. Do not edit code.
3. If full validation is blocked, say what remains unverified.
