# Jira Epic Model

## Standard

Each project is anchored to a single Jira Epic.

## Epic responsibilities

1. Hold the project-level summary.
2. Group the project's child issues.
3. Receive weekly status comment drafts.
4. Record short commercial and delivery notes.

## Suggested Epic fields

1. Epic name
2. Epic key
3. Status
4. Target milestone or delivery window
5. Stakeholder or customer context
6. Delivery risk summary

## Comment usage

Use Epic comments for weekly updates and short handoff notes.
